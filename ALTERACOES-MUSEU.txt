IMPORTANTE — Pipinho Finance:
O link exato do repositório público não pôde ser confirmado. O botão "Buscar no GitHub"
abre uma pesquisa no perfil, sem afirmar que ela leva diretamente ao projeto.
Quando houver URL oficial, adicione 'href: "https://..."' ao objeto de Pipinho em
'data/projects.ts' e o botão passará automaticamente a ser "Ver repositório".

Executar: npm install && npm run dev
Conferir: npm run build
