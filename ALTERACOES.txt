PORTFÓLIO — WEB / APPS / ENGINEERING
==================================

INSTRUÇÕES
1. Descompacte este arquivo.
2. Se estiver usando o ZIP COMPLETO, abra a pasta portfolio-guilherme-main.
3. Instale as dependências com "npm install" e execute "npm run dev".
4. Teste as rotas /, /web, /apps, /engineering, /lab e /about.

O QUE FOI MUDADO
- Mundo WEB mantido.
- Mundo APPS: vitrine de produtos, SIRG e Wedding BF.
- Mundo ENGINEERING: caderno técnico com quatro projetos, um experimento visual por projeto.
- Menu e página inicial atualizados.
- /dados redireciona para /engineering.
- /system redireciona para /apps.
- DataWorld.tsx e SystemWorld.tsx removidos do ZIP completo.

PARA APLICAR APENAS O ZIP DE ALTERAÇÕES
1. Extraia o conteúdo do pacote na raiz do seu projeto existente.
2. Permita a substituição de arquivos coincidentes.
3. Exclua os arquivos antigos components/DataWorld.tsx e components/SystemWorld.tsx (não são mais utilizados).
4. Rode "npm install" e "npm run dev".

OBSERVAÇÃO IMPORTANTE
Os mockups APPS e as demonstrações ENGINEERING são ilustrações técnicas interativas
montadas para o portfólio. Eles não são capturas reais e não executam o código dos
repositórios. Os links externos levam aos repositórios identificados.

VERIFICAÇÃO
- Sintaxe dos arquivos TypeScript/TSX: validada.
- Sintaxe do CSS: validada.
- Build completo: não pôde ser realizado aqui porque a instalação das dependências
  expirou por tempo de execução. Antes de publicar, execute npm run build.
